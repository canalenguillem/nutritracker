# Implementation status

The project is implemented sequentially according to the phases requested by the
product owner. Phase 4 is complete: manual meal registration, the daily diary
and its totals have been compiled, started and verified against the running
stack, both through the API and by driving the screens in a browser. The user
profile, photograph upload and AI analysis remain intentionally deferred.

Run the development application with:

```bash
docker compose up --build
```

See [`README.md`](./README.md) for the complete setup and verification guide.
