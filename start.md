# Implementation status

The project is implemented sequentially according to the phases requested by the
product owner. Phase 10 is complete: the day now reports a calorie deficit or
surplus, comparing what was eaten against resting expenditure, daily living and
the training recorded. Running the food estimator against OpenAI requires a key
in `.env`.

Run the development application with:

```bash
docker compose up --build
```

See [`README.md`](./README.md) for the complete setup and verification guide.
